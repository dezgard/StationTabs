# Star Empire Station Storage Tabs

Station Storage Tabs makes large player-owned station inventories easier to
browse. It adds a compact category strip to the existing Storage view so cargo
can be narrowed down without changing how the station itself works.

## Features

- Builds useful categories from the item information supplied by the game.
- Includes an **All** view for the complete station inventory.
- Places the category grid inside Storage, directly below the search field.
- Keeps station plugin rows visible while cargo is filtered.
- Resets the list position cleanly when changing category.

## Using the mod

1. Install the `.semod` with Star Empire Mod Manager.
2. Enable **Star Empire Station Storage Tabs**.
3. Open a player-owned station normally and select **Storage**.
4. Choose a category below the Storage search field.

Disable or uninstall the mod through the Manager to restore the normal Storage
view.

## Safety and compatibility

The category controls only appear when the game's original player-station
Storage view is already open. The mod cannot open inaccessible station windows,
bypass docking permissions, alter cargo, or change station access rules.

Tested with Star Empire 0.4.62 and 0.4.63 using Mod Loader API 2.
